# SEARCH_CONSOLE_GUIDE Taxi Ayud

## Configuración inicial

1. Verifica la propiedad de dominio `taxiayud.es`.
2. Añade también la variante URL `https://www.taxiayud.es/` si quieres inspección rápida por URL.
3. Envía el sitemap: `https://www.taxiayud.es/sitemap.xml`.

## Inspección prioritaria

Solicita indexación de:

- Home.
- Taxi Calatayud.
- Taxi cerca de mí.
- Estación AVE.
- Monasterio de Piedra.
- Balnearios.
- Comarca/pueblos.
- A-2 avería pasajeros.
- Zaragoza.
- Aeropuerto Zaragoza.
- FREENOW Calatayud.

## Qué revisar cada semana

- Páginas indexadas y no indexadas.
- Consultas con impresiones para "taxi Calatayud", "taxi cerca de mí", "taxi Monasterio de Piedra", "taxi A-2 Calatayud".
- CTR bajo con muchas impresiones: mejorar title/meta.
- URLs antiguas `.com`, WordPress o `hello-world`.
- Core Web Vitals móvil.
- Canibalización: dos páginas compitiendo por la misma consulta.

## Después de cada despliegue

- Probar home con inspección de URL.
- Enviar sitemap si se han creado o eliminado páginas.
- Inspeccionar las landings modificadas.
- Esperar a que Google recalcule favicon/snippet; puede tardar días o semanas.
